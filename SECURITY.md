# Security Policy

## Supported versions

Security fixes are released for the latest 2.x version on PyPI.

## Reporting a vulnerability

Please do not open a public issue for a security problem. Report it privately through
[GitHub security advisories](https://github.com/grounded-ai/grounded_ai/security/advisories/new)
or by email to support@groundedai.tech.

Include what you found, how to reproduce it, and the version affected. You can expect a first
reply within a few days.
